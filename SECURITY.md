# Security policy

Do not report vulnerabilities in public issues or pull requests. Use
[GitHub private vulnerability reporting](https://github.com/bacumi-tech/bacumi-web/security/advisories/new)
and remove credentials, customer data, and unnecessary personal information.

The website is public browser code and is never trusted to enforce identity,
organization access, paid entitlement, or licensing. Suspected credential exposure,
unsafe deployment configuration, dependency compromise, or misleading trust/legal
behavior is in scope.
